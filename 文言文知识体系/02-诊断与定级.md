# 诊断与定级

先做朗读观察，再做四组短题。诊断通常用 40 分钟，结果用于确定起点。

## 什么时候做

- **接手新班**：第一周做一次，知道班里分布在哪几级。
- **开学/学期初**：确认假期有没有退步。
- **专题课前**：只做相关的一组，不用全做。
- **学生说「我听不懂」**：做一次，比问「哪里不懂」准。

**不要**每次备课都做。一次定级管一个阶段，2—3 个月重测一次就够。

## 四组题测什么

| 组 | 对应能力级 | 测什么 | 题量 |
| --- | --- | --- | --- |
| 第 0 组 | L0 | 朗读、复述、代词指代（老师观察，不计分） | 4 项 |
| 第 1 组 | L1 | 词义：古今异义、通假、代词 | 5 题 |
| 第 2 组 | L2 | 句法：通假、省略、判断句、翻译 | 4 题 |
| 第 3 组 | L3 | 翻译：关键词、语序、采分点 | 1 段 |
| 第 4 组 | L4 | 篇章：概括、取证、人物评价 | 2 题 |

第 1—4 组各 10 分，7 分为筛查线，首个低于 7 分的组决定起点。每一级的过关任务和复测另行记录。

## 怎么用

1. 打印 [诊断卷](诊断/诊断卷.md)，学生独立完成，不查字典、不讨论。
2. 老师按 [诊断答案](诊断/诊断答案.md) 批改，只记四组总分，不逐题讲。
3. 把四个分数按「词义,句法,翻译,篇章」顺序填进脚本：

```powershell
python -B -X utf8 "文言文知识体系/诊断/定级.py" --scores 8,6,7,9
```

4. 脚本输出起点等级、主攻知识域、过关任务和下一步。按这个结果排课或自学。

第 0 组未通过的学生可以直接进入 L0，四组分数留空。

```powershell
python -B -X utf8 "文言文知识体系/诊断/定级.py" --l0 fail
```

四组都过线时先定 L4。达到 L5 的准入标准后，可让老师提供一套高考文言真题的百分比、实际用时和错因复核情况。分数至少 85%、用时不超过 35 分钟、老师已核对错因（满分可确认无失分），三项齐备才进入 L5。进入后继续换真题观察稳定性。

```powershell
python -B -X utf8 "文言文知识体系/诊断/定级.py" --scores 9,9,8,9 --exam-percent 85 --exam-minutes 35 --exam-reviewed
```

讲练后用[学生版复测](练习/学生版/分级复测.md)和[教师评分](练习/教师版/分级复测-答案.md)换材料检测。L5 复测是课内迁移，真题证据单独记录。

## 三个判断原则

**① 看第一个低分组，不看平均分。** 四个分数平均 7.5 但句法只有 4，起点定 L2，不是 L3。短板决定能不能往上走。

**② 不跨级补。** L1 词义不过关，直接上 L3 翻译，只会重复犯错。先把本级过关任务做掉。

**③ 定级看任务，不看年级。** 六年级能过 L2 就从 L2 开始；高一 L1 还在错就回 L1。年级只用于选材料，不用于定层级。

## 常见问题

**「一个班 40 人，一个个跑脚本？」** 不用。抽 5—8 个不同层次的学生做，看分布；或者整班做第 1、2 组，统计各分数段人数，按多数人所在层级定课堂起点，个别学生单独补。

**「分数在及格线附近怎么定？」** 按低的那一级定。7 分是「可以进下一级」，6 分就是「还没到」，不要四舍五入。

**「多久重测？」** 完成一级的过关任务后重测一次；或者 2—3 个月一次。不要每周测，测多了学生会产生「被贴标签」的感觉。

**「定级结果要不要告诉学生？」** 告诉层级和下一步任务，不比较学生之间的层级。重点是「你现在练这个」，不是「你在第几级」。
