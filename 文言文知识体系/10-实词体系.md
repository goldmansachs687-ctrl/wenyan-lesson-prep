# 实词体系

实词丢分只有五种原因：**古今异义没看出来、通假没认出来、一词多义选错义项、活用没判断、偏义复词按字面解**。对应的五个判断动作练熟，实词题就稳了。

不要背「120 个实词」的清单。清单只能应付选择题，读不懂句子还是白搭。正确顺序是：**先看搭配和语境，再定义项，最后用课内同形句验证**。

## 一、古今异义

### 四类变化

| 类型 | 规律 | 课内例 |
| --- | --- | --- |
| 词义扩大 | 专指变泛指 | 「江」「河」原专指长江、黄河，后泛指河流 |
| 词义缩小 | 泛指变专指 | 「金」原泛指金属，后多指黄金 |
| 词义转移 | 所指对象换了 | 走：跑→步行；去：离开→前往；汤：热水→菜汤 |
| 感情色彩变化 | 褒贬变了 | 卑鄙：身份低微（中性）→品质恶劣（贬义）；爪牙：得力助手（褒）→帮凶（贬） |

### 高频古今异义（课内必考）

| 词 | 古义 | 今义 | 课内例 |
| --- | --- | --- | --- |
| 走 | 跑 | 步行 | 兔**走**触株·《守株待兔》三下 |
| 去 | 离开 | 前往 | 太丘舍**去**·《陈太丘与友期行》七上 |
| 妻子 | 妻子和儿女 | 男子的配偶 | 率**妻子**邑人来此绝境·《桃花源记》八下 |
| 交通 | 交错相通 | 运输事业 | 阡陌**交通**·《桃花源记》八下 |
| 无论 | 不要说，更不必说 | 表条件的连词 | **无论**魏晋·《桃花源记》八下 |
| 卑鄙 | 身份低微、见识短浅 | 品质恶劣 | 先帝不以臣**卑鄙**·《出师表》九下 |
| 痛恨 | 痛心遗憾 | 深切憎恨 | 未尝不叹息**痛恨**于桓灵也·《出师表》九下 |
| 开张 | 扩大 | 店铺开业 | 诚宜**开张**圣听·《出师表》九下 |
| 博士 | 专掌经学的学官 | 学位 | 治经为**博士**邪·《孙权劝学》七下 |
| 往事 | 历史 | 过去的事 | 见**往事**耳·《孙权劝学》七下 |
| 汤 | 热水 | 菜汤 | 媵人持**汤**沃灌·《送东阳马生序》九下 |
| 假 | 借 | 虚假 | 以是人多以书**假**余·《送东阳马生序》九下 |

**判断方法**：把今义代进去，如果句子讲不通或别扭，就是古今异义。不要问「这个词古义是什么」，要问「这句话用今义讲得通吗」。

## 二、通假字

### 三条线索（同时满足才是通假）

1. **按本字讲不通**——用这个字的本义解释，句子别扭。
2. **读音相同或相近**——包括声旁相同、声母或韵母相近。
3. **换成借字后通顺**——代回去，句子立刻讲通。

### 高频通假

| 通假 | 本字 | 课内例 |
| --- | --- | --- |
| 说 | 悦 | 不亦**说**乎·《论语》十二章七上 |
| 有 | 又 | 吾十**有**五而志于学·《论语》十二章七上 |
| 不 | 否 | 尊君在**不**·《陈太丘与友期行》七上 |
| 反 | 返 | 始一**反**焉·《愚公移山》八上 |
| 见 | 现 | 才美不外**见**·《马说》八下 |
| 食 | 饲 | **食**马者不知其能千里而**食**也·《马说》八下 |
| 邪 | 耶 | 其真无马**邪**·《马说》八下 |
| 属 | 嘱 | **属**予作文以记之·《岳阳楼记》九上 |
| 具 | 俱 | 百废**具**兴·《岳阳楼记》九上 |
| 女 | 汝 | 诲**女**知之乎·《论语》（课外） |

**易错**：通假和古今异义容易混。「走」不是通假，是词义转移；「说」通「悦」才是通假。判断标准是「本字能不能讲通」——「走」按「跑」讲得通，只是今义变了，所以不是通假。

## 三、一词多义

### 定项四步

1. **看搭配**：后面接人、接物、接地点，义项不同。例：「顾」接人（顾野有麦场）是「看」，接「之」（三顾臣于草庐）是「拜访」。
2. **看主语**：谁做的，决定词义。例：「属」——「忠之属也」是「类」，「属予作文」是「嘱」。
3. **代入验证**：把候选义项逐个代回原句，读一遍，选最通的那个。
4. **课内同形句对照**：找学过的同字句，比较搭配。这是最可靠的一步。

### 高频多义词（课内至少两义）

| 词 | 义项一 | 义项二 | 义项三 |
| --- | --- | --- | --- |
| 顾 | 回头看（元方入门不**顾**） | 拜访（三**顾**臣于草庐） | 看（**顾**野有麦场） |
| 举 | 被选拔（傅说**举**于版筑之间） | 发动（**举**大计亦死） | 举起（**举**杯） |
| 属 | 类（忠之**属**也） | 嘱托（**属**予作文） | 连接（**属**引凄异） |
| 故 | 旧的知识（温**故**而知新） | 原因（问其**故**） | 所以（**故**天将降大任） |
| 间 | 参与（又何**间**焉） | 中间（颓然乎其**间**者） | 私下（**间**至军中） |
| 期 | 约定（陈太丘与友**期**行） | 期限（**期**年之后） | 希望（**期**在必醉） |

## 四、词类活用

### 六类

| 类型 | 判断 | 课内例 |
| --- | --- | --- |
| 名词作动词 | 名词后面带了宾语，或处在谓语位置 | 腰白玉之环（**腰**：在腰间佩戴）·《送东阳马生序》九下 |
| 名词作状语 | 名词在动词前，表示方式、工具、方位 | 其一**犬**坐于前（像狗一样）·《狼》七下 |
| 形容词作名词 | 形容词处在主语或宾语位置 | 温**故**而知**新**（旧知识、新知识）·《论语》十二章七上 |
| 动词作名词 | 动词处在主语或宾语位置 | 惧有**伏**焉（伏兵）·《曹刿论战》九下 |
| 使动用法 | 「使……怎么样」 | **凄**神**寒**骨（使……凄凉、使……寒冷）·《小石潭记》八下 |
| 意动用法 | 「认为……怎么样」 | 渔人甚**异**之（认为……奇异）·《桃花源记》八下 |

**判断顺序**：① 这个字本来的词性是什么？② 在本句里它充当什么成分？③ 成分和词性对不上，就是活用。

**易错**：「犬坐」不是「狗坐着」，是「像狗一样坐着」——名词作状语，不是名词作动词。「凄神寒骨」不是「凄凉的神、寒冷的骨」，是「使神凄凉、使骨寒冷」——使动。

## 五、偏义复词

两个近义或反义语素组合，实际只取一个的意思。

| 词 | 偏指 | 课内例 |
| --- | --- | --- |
| 异同 | 偏「异」 | 陟罚臧否，不宜**异同**·《出师表》九下 |
| 作息 | 偏「作」 | 昼夜勤**作息**（《孔雀东南飞》全诗，本册底本只收小序） |
| 父兄 | 偏「兄」 | 我有亲**父兄**（《孔雀东南飞》全诗，同上） |

**判断**：两个语素意思相反或相对，代进句子只有一个讲得通，就是偏义复词。

## 六、按语义场记高频词

散着背 120 个词记不住，按「这件事通常怎么说」分组，一组记一串。

| 语义场 | 常用词 |
| --- | --- |
| 行走移动 | 走（跑）、去（离开）、行、徙、适（往）、诣（到……去）、趋（快走） |
| 看 | 顾（回头看/拜访）、视、观、瞻、窥、眺 |
| 说 | 曰、云、谓（对……说）、语（告诉）、告、谕（告诉） |
| 给予 | 与、予、遗（送）、赐、赠 |
| 拿取 | 持、执、操、取、援（拉）、夺 |
| 攻伐 | 伐、攻、击、袭（偷袭）、侵 |
| 治理 | 治、理、牧、宰 |
| 官职变动 | 拜（授官）、除（授职）、迁（调任/升）、徙（调职）、擢（提升）、黜（罢免） |
| 死亡 | 崩（帝王）、薨（诸侯）、卒（大夫）、死（庶人）、殁 |
| 时间 | 尝（曾经）、既（已经）、俄（不久）、顷（不久）、寻（不久）、旋（随即） |

官职变动这一类要特别记，高考史传题几乎年年出现，且「迁」是升是降要看语境——「迁」后可接「为」「左迁」（降职）。

## 怎么练

1. **每天 5 个词，只做三件事**：找一句课内原句、说出本句义、说出判断依据。不抄定义。
2. **建「同字卡」**：一个字收 3—5 个句子，正面原句，背面本句义。复习时只看正面，能说出义项才算会。
3. **活用专项**：拿 10 个名词，判断它在句中是名词、动词还是状语。判断标准只看成分，不看意思。
4. **迁移**：用课外一句没见过的句子，测同一个字，能定项才算掌握。
