# 学生手册

这套东西不是让你「多背」，是让你知道**自己现在卡在哪、下一步该练什么**。

## 第一步：先做一次诊断

打开 [诊断卷](诊断/诊断卷.md)，40 分钟做完，别查字典。做完让老师批，或者自己对 [诊断答案](诊断/诊断答案.md)。

把四个分数填进定级脚本（老师会帮你跑，或者自己用）：

```powershell
python -B -X utf8 "文言文知识体系/诊断/定级.py" --scores 8,6,7,9
```

脚本会告诉你：你现在在哪一级、最弱的是哪块、下一步该读哪份文件。

**定级不是给你贴标签**，是告诉你从哪开始。六年级定到 L2 很正常，高一还在 L1 也不丢人——按层级补，比跟着班级硬撑快。

定级之后，直接拿对应级别的 [学习包](分级/README.md)：里面有一张「知识清单」，学完一条勾一条；还有必读章节和必练题号，不用自己找。

## 每天 20 分钟怎么用

| 时间 | 做什么 |
| --- | --- |
| 5 分钟 | 读一段课内短文，出声读，读顺为止 |
| 10 分钟 | 练**一个**动作：解释 3 个词 / 断 1 句 / 译 1 句 |
| 5 分钟 | 把今天的错写进错题本（只写错因，不抄答案） |

**不要**一天练六个知识点。一天一个动作，一周五个动作，比一天囫囵吞五个有效。

## 每周做什么

| 周次 | 任务 |
| --- | --- |
| 第 1 周 | 按定级结果读对应的知识域文件（[10](10-实词体系.md)—[15](15-文化常识.md)），只读你那一级要用的部分 |
| 第 2—3 周 | 按 [03](03-路径-小学.md)／[04](04-路径-初中.md)／[05](05-路径-高中.md) 的当前轮次，每天练一个动作；配套题在 [分级题库](练习/README.md) |
| 第 4 周 | 用一周前的材料复测同一个动作，看是否真会 |

**复测很重要**。当天做对可能是记住了答案，隔一周换一篇还能做对，才是真会。

## 错题本怎么记

只记三样，一页写三道题：

```text
【原句】兔走触株，折颈而死。
【我答】走路
【错因】把今义套进去了；「走」在文言里是「跑」
```

**不要**抄正确答案，不要抄定义。错因写不出来，说明还没懂，回去看对应文件的那一节。

错因按五类归：词义错 / 关系判断错 / 成分没补 / 漏译 / 审题表达。一周看一次，哪类最多就先补哪类。

## 三个不要

**① 不要背译文。** 背了译文，换一篇还是不会。要背的是「判断步骤」：先看什么、再看什么、怎么验证。

**② 不要一上来就查字典。** 先猜，说出依据，再查。查完对照：猜对了说明方法对，猜错了看是哪一步错了。直接查，练的是查字能力，不是阅读能力。

**③ 不要只做选择题。** 选择题可以蒙，翻译和概括蒙不了。平时练习以翻译、概括为主，选择题为辅。

## 各阶段该盯什么

| 你的层级 | 只盯这三件事 |
| --- | --- |
| L0 | 读顺、说清谁做了什么、认出「之」指谁 |
| L1 | 5 个加点词能解释 4 个、能说出依据 |
| L2 | 译文语序对、省略补上、四类句式认得出 |
| L3 | 译完能圈出采分点、说清每处扣分原因 |
| L4 | 每个判断都能引一句原文、双材料能说清关系 |
| L5 | 四类题型有固定步骤、错因能说到具体动作 |

## 卡住了怎么办

- **读不懂整篇**：先不管字词，用一句话说「这篇讲谁、做了什么事」。说不出来，回 L0。
- **词都认识，句子还是不懂**：多半是省略没补或语序没调，看 [12 句式](12-句式体系.md)。
- **翻译自我感觉对，总扣分**：看 [14 翻译](14-翻译体系.md) 的三类固定失分，八成是漏了否定词或范围词。
- **概括题不会写**：记住格式「一句话结论 + 一句原文证据」，不要抄整段。
- **考试时间不够**：看 [05 高中路径](05-路径-高中.md) 的时间分配表，先保证概括题定位时间。

需要老师配合的，把这份手册和诊断结果一起给老师，比自己闷头刷题快。
