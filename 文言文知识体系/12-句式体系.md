# 句式体系

文言句式和现代汉语的差别只有四条：**判断不用「是」、被动不用「被」、成分常省略、语序会颠倒**。四条各有标志词，认标志比背定义快。

## 一、判断句

| 标志 | 课内例 | 翻译 |
| --- | --- | --- |
| ……者，……也 | 陈胜**者**，阳城人**也**·《陈涉世家》九下 | 陈胜是阳城人 |
| ……，……也 | 环滁皆山**也**·《醉翁亭记》九上 | 环绕滁州的都是山 |
| ……者，…… | 北山愚公**者**，年且九十·《愚公移山》八上 | 北山有个叫愚公的人，年纪将近九十 |
| 乃 / 则 / 即 / 皆 / 悉 / 本 / 诚 | 当立者**乃**公子扶苏·《陈涉世家》九下 | 应当立为皇帝的是公子扶苏 |
| 是（少见，汉代以后） | 不知木兰**是**女郎·《木兰诗》（课外） | 不知道木兰是女子 |
| 非（否定判断） | 城**非**不高也·《得道多助，失道寡助》八上 | 城墙不是不高 |

**翻译要点**：一定要补出「是」或「就是」。漏掉「是」是判断句最常见的失分。

**易错**：「是」在先秦多作指示代词「这」，不是判断词。例：「**是**知也」——「这」才是智慧。

## 二、被动句

| 标志 | 课内例 | 翻译 |
| --- | --- | --- |
| 为 / 为……所…… | 身**为**宋国笑·《守株待兔》三下 | 自己被宋国人耻笑 |
| 为……所…… | 其印**为**予群从**所**得·《活板》七下 | 那些字印被我的子侄们得到 |
| 见 / 见……于…… | 才美不外**见**·《马说》八下（此例为通假「现」，非被动） | — |
| 于 | 不拘**于**时·《师说》必修上 | 不受时俗限制 |
| 被 | 同是被逼迫·《孔雀东南飞》（课外） | — |
| 无标志（意合被动） | 帝感其诚·《愚公移山》八上 | 天帝被他的诚心感动 |

**翻译要点**：译出「被」。无标志被动句最容易漏，判断依据是「主语是受事者」。

**易错**：「见」既可以是「看见」，也可以是「被」。「才美不外见」的「见」通「现」，不是被动。要看句子：主语是施事还是受事。

## 三、省略句

| 类型 | 课内例 | 补什么 |
| --- | --- | --- |
| 省主语 | 过中不至，太丘舍去，去后乃至·《陈太丘与友期行》七上 | （友）过中不至，（太丘）舍去，（太丘）去后（友）乃至 |
| 省宾语 | 问（之）所从来·《桃花源记》八下 | 省略代词「之」 |
| 省介词 | 一厝（于）朔东，一厝（于）雍南·《愚公移山》八上 | 省「于」 |
| 省谓语 | 一鼓作气，再（鼓）而衰，三（鼓）而竭·《曹刿论战》九下 | 省「鼓」 |

**翻译要点**：先做一遍「谁—做什么—对谁」，把省略的成分用括号补在原文上，再翻译。

**易错**：主语省略不补，一段话里三个人的动作分不清谁做的。这是初中翻译最大的失分点。

## 四、倒装句

### 宾语前置

| 类型 | 标志 | 课内例 | 正常语序 |
| --- | --- | --- | --- |
| 疑问代词作宾语 | 何、谁、孰 | 何陋**之**有·《陋室铭》七下 | 有何陋 |
| 否定句代词作宾语 | 不、未、莫 | 古之人不余**欺**也·《石钟山记》选必下 | 不欺余 |
| 用「之」「是」提宾 | ……之……／……是…… | 唯利**是**图（课外） | 唯图利 |

### 状语后置（介词结构后置）

| 标志 | 课内例 | 正常语序 |
| --- | --- | --- |
| 于…… | 群儿戏**于庭**·《司马光》三上 | 群儿于庭戏 |
| 以…… | 蒙辞**以军中多务**·《孙权劝学》七下 | 蒙以军中多务辞 |

**翻译要点**：把「于/以」结构提到动词前，译成「在……」「用……」。

### 定语后置

| 标志 | 课内例 | 正常语序 |
| --- | --- | --- |
| ……之……者 | 马**之**千里**者**·《马说》八下 | 千里之马 |
| ……者 | 遂率子孙荷担**者**三夫·《愚公移山》八上 | 荷担之子孙三夫 |

### 主谓倒装

| 课内例 | 正常语序 |
| --- | --- |
| 甚矣，汝之不惠·《愚公移山》八上 | 汝之不惠甚矣 |

## 五、固定结构

| 结构 | 意思 | 课内例 |
| --- | --- | --- |
| 所以 | 用来……的／……的原因 | **所以**传道受业解惑也·《师说》必修上 |
| 何以 | 凭什么、为什么 | **何以**战·《曹刿论战》九下 |
| 孰与 / 孰若 | 与……相比怎么样／哪里比得上 | **孰若**孤·《孙权劝学》七下 |
| 不亦……乎 | 不也……吗 | **不亦**说**乎**·《论语》十二章七上 |
| 何……之有 | 有什么……呢 | 何陋**之有**·《陋室铭》七下 |
| 得无……乎 | 恐怕……吧 | **得无**异乎（课外） |
| 无乃……乎 | 恐怕……吧 | **无乃**不可乎（课外） |
| 有所 / 无所 | 有……的／没有……的 | **有所**广益（课外） |

## 判断流程

拿到一句话，按顺序问五个问题：

1. 有没有「者、也、乃、则」？→ 可能是判断句。
2. 主语是受事者吗？有没有「为、见、于」？→ 可能是被动句。
3. 主语或宾语缺了吗？→ 省略句，先补。
4. 语序和现代汉语一样吗？→ 不一样就是倒装，调回来。
5. 有没有「所以、何以、孰若」？→ 固定结构，按固定译法。

**不要先想术语**。先判断「这句话哪里不对劲」，术语只是给不对劲的地方命名。

## 翻译时的处理顺序

补省略 → 调语序 → 译固定结构 → 补判断词/被动词 → 通读。顺序错了会反复改。
