# 从这里开始

这个目录解决一件事：**一个初学文言文的学生，按什么顺序学、学到什么程度算过关，最后能应对高考题；老师怎么判断学生卡在哪、该补什么。**

不用从头读到尾。按身份挑一条路走。

## 第一次用，三步

1. **做一次诊断**：打印 [诊断卷](诊断/诊断卷.md)，40 分钟，四个分数。
2. **定级**：按[诊断与定级](02-诊断与定级.md)输入四组分数，朗读观察未通过时直接给 L0。
3. **按等级走**：领本级学习包，完成指定练习，再用[换材复测](练习/README.md)检查掌握情况。

不想跑脚本，就看 [能力分级标准](01-能力分级标准.md) 的六级表格，自己对号。

**知道自己是哪一级之后，直接拿对应的学习包**——它把这一级要学什么、读哪节、练哪题、怎么检测都列好了：

| 级 | 学习包 | 一句话 |
| --- | --- | --- |
| L0 | [认读包](分级/L0-认读包.md) | 读得下来，说得出故事 |
| L1 | [词义包](分级/L1-词义包.md) | 遇到生词会猜，猜得有依据 |
| L2 | [句法包](分级/L2-句法包.md) | 看得出一句话的骨架 |
| L3 | [翻译包](分级/L3-翻译包.md) | 翻译不丢分，知道扣在哪 |
| L4 | [篇章包](分级/L4-篇章包.md) | 读懂整篇，能引原文证明 |
| L5 | [应试包](分级/L5-应试包.md) | 四类题稳定，错因说得清 |

## 我是家长

只需要看两样：

1. 孩子现在在哪一级（[诊断](02-诊断与定级.md) 的结果，L0 到 L5）。
2. 这一级的过关任务是什么（[分级标准](01-能力分级标准.md) 对应那一行）。

不用管「讲了什么」，看「能不能做到」。能做到就是会了，做不到就是还没会。

## 这个目录不做什么

- 不复制原文。要查原句、教材出处、字义，去 `文言文语料库/`。
- 不代替老师的讲义。老师的原稿在 `文言文教学/教师备课资料/`。
- 不押题。L5 用课内长篇练高考题型，不是真题预测。
