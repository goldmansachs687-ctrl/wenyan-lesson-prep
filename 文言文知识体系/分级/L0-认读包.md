# L0 认读包

**一句话**：把一篇短古文读下来，知道它在讲一件什么事。

**适用**：小学三、四年级，或刚开始接触文言文的初中生。

---

## 过关任务

独立读《司马光》，做到三件事：

1. 朗读，两处停顿正确；
2. 用自己的话说这个故事；
3. 指出「光持石击瓮破之」里「之」指什么。

三项都做到，进 L1。详见 [能力分级标准](../01-能力分级标准.md)。

## 本级知识清单

学完一条勾一条。**不要求背术语，只要求做得到。**

### 朗读（3 条）

- [ ] **标点处必停**：逗号小停，句号大停，问号叹号读出语气。
- [ ] **主谓之间停**：「群儿／戏于庭」——谁，在哪儿玩。不要说「状语后置」，只说「谁／做什么」。
  - 例：群儿戏于庭·《司马光》三上
- [ ] **长句按意思切**：「光／持石／击瓮／破之」——一个人，三个动作，一路做下去。

### 动作词（2 条）

- [ ] **圈出所有动词**：一句话里有几个动作，就有几个动词。
  - 例：持、击、破·《司马光》三上
- [ ] **一个动作问一次「谁做的」**：动作的主语常常省略，要能补出来。

### 复述（2 条）

- [ ] **三问复述**：谁？做了什么？结果怎样？三句话说完一个故事。
- [ ] **按顺序说**：不能跳着说，先发生什么、后发生什么。

### 代词（1 条）

- [ ] **「之」「其」往前找**：它指谁、指什么，一定在前文出现过。
  - 例：破**之**（指瓮）·《司马光》三上

### 古今异义（1 条，只要求有意识）

- [ ] **知道有些字古今不一样**：走＝跑，去＝离开。不要求记全，要求「读到别扭时想一想」。
  - 例：兔**走**触株·《守株待兔》三下

## 必练

- [L0 认读 8 题](../练习/学生版/L0-认读.md)，口头做，老师记录。
- 每天朗读一篇课内小古文，读三遍：第一遍读顺，第二遍圈动作，第三遍复述。

## 检测

8 项中 6 项通过 → 进 L1。

4—5 项 → L0 再走一轮，两周后重测。
3 项以下 → 先解决朗读，不讲词义。

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 逐字蹦 | 一个字一个字读，不成句 | 跟读，老师读一句他跟一句，不讲意思 |
| 读得顺但说不出 | 只练了读，没练复述 | 用「谁—做什么—结果」三格填空 |
| 代词全指错 | 没有指代意识 | 每遇「之、其」画箭头连到所指的词 |
| 把今义套进去 | 「走」答走路 | 正常，L1 再专项练，现在只要他有「不一样」的意识 |

## 下一级预告

L1 开始学「猜词」：遇到没学过的字，能用组词、换词、上下文猜出来，并说出依据。本级只要求「读顺、说清」，L1 才要求「猜得有理」。

## 老师提醒

这个阶段最忌讲语法。一节课讲三个术语，不如让学生把一篇读五遍、说三遍。读不顺，后面全是空中楼阁。
