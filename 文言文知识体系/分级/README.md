# 分级学习包

六份学习包，一级一份。**按级别拿，一次拿一份，不要跨级。**

学习包和知识域文件的分工：

- **学习包**（本目录）：告诉你在这一级要学什么、学到什么程度、读哪节、练哪题。用于「学」。
- **知识域文件**（[实词](../10-实词体系.md)、[虚词](../11-虚词体系.md)…）：把一个知识点的全部内容摊开。用于「查」。

先拿学习包，遇到需要展开的地方再点进知识域。不要一上来就通读知识域——那是参考手册，不是教材。

读法：横着看是「这个知识点在哪几级出现」，竖着看是「这一级要学什么」。

三条规律：

1. **同一知识点会跨级重现**，但要求不同。省略句在 L2 是「认得出、补得上」，到 L3 是「翻译时不忘补」。
2. **前两级只碰少数知识点**，L2 开始密集，L4 换赛道（从字句到篇章）。
3. **L5 没有新知识点**，只有「稳定」和「归因」。所以 L5 的包最短，重点在练和查。

## 怎么用

**老师**：

1. 按 [诊断](../02-诊断与定级.md) 定级，或按班级多数人的层级定起点。
2. 拿对应学习包，按「知识清单」排课——一条清单项通常对应一个教学动作。
3. 「必练」里的题号直接用，答案在教师版。
4. 「检测」过关再进下一级，不按教学进度硬推。

**学生**：

1. 先定级，拿到自己的级别。
2. 学习包的「知识清单」是任务单，学完一条勾一条。
3. 只读「必读章节」列出的部分，不要通读知识域。
4. 「必练」做完，按「检测」判断能不能升级。

## 一句话

**学习包是路线，知识域是地图。** 先按路线走，迷路了再翻地图。反过来——先通读地图再走——多数人走不完。
