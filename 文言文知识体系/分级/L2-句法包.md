# L2 句法包

**一句话**：看得出一句话的骨架，知道哪里省略了、哪里倒装了。

**适用**：初中七、八年级，或 L1 过关后。

---

## 过关任务

给 80 字文言段（含 1 个判断句、1 个被动句、1 处省略、1 处倒装）：

1. 译成通顺现代汉语；
2. 标出四种句式的句子；
3. 补出省略的主语或宾语。

四类句式均辨认正确、省略补对且译文通顺，算过关。

## 本级知识清单

### 判断句（2 条）

- [ ] **认标志**：……者，……也／……，……也／乃／则／皆／非。
  - 例：陈胜**者**，阳城人**也**·《陈涉世家》九下
- [ ] **译出「是」**：漏掉「是」是判断句最常见的失分。
  - 例：此**诚**危急存亡之秋**也** → 这确实是……的时候·《出师表》九下

### 被动句（2 条）

- [ ] **认标志**：为／为……所……／见／于／被。
  - 例：身**为**宋国笑·《守株待兔》三下
- [ ] **无标志被动**：主语是受事者，也要译「被」。
  - 例：帝感其诚 → 天帝被他的诚心感动·《愚公移山》八上

### 省略句（3 条）

- [ ] **先做「谁—做什么—对谁」**：一段话里几个人在动，不补必乱。
  - 例：过中不至，太丘舍去，去后乃至·《陈太丘与友期行》七上
- [ ] **补主语、补宾语、补介词**。
  - 例：一厝（于）朔东·《愚公移山》八上
- [ ] **补完再译**：不要边译边猜。

### 倒装四类（4 条）

- [ ] **宾语前置**：何陋**之**有 → 有何陋·《陋室铭》七下
- [ ] **状语后置**：蒙辞**以军中多务** → 用军中事务多来推托·《孙权劝学》七下
- [ ] **定语后置**：马**之**千里**者** → 千里之马·《马说》八下
- [ ] **主谓倒装**：**甚矣**，汝之不惠 → 汝之不惠甚矣·《愚公移山》八上

### 词类活用（4 条）

- [ ] **名词作状语**：名词在动词前，表方式。其一**犬**坐于前 → 像狗一样·《狼》七下
- [ ] **名词作动词**：名词处在谓语位置。**腰**白玉之环 → 在腰间佩戴·《送东阳马生序》九下
- [ ] **使动**：使……怎么样。**凄**神**寒**骨·《小石潭记》八下
- [ ] **意动**：认为……怎么样。渔人甚**异**之·《桃花源记》八下

**判断顺序**：这个词本来是什么词性 → 在本句充当什么成分 → 对不上，就是活用。

### 18 个虚词（先精 8 个）

- [ ] **精讲 8 个**：之、而、以、其、于、为、者、也。每个至少 2 种用法。
- [ ] **随文 10 个**：何、乎、乃、且、若、所、焉、因、与、则。遇到再补。

判断方法：圈出虚词两侧，看它连接什么、指代谁。详见 [虚词体系](../11-虚词体系.md)。

## 必练

- [L2 句法 12 题](../练习/学生版/L2-句法.md)，限时 30 分钟。
- **句式本**：分四栏（判断、被动、省略、倒装），每学一篇把新句子填进去，写清标志词。
- 每周一次「补主语」练习：拿一段课内叙事，只补主语，不翻译。

## 检测

24 分满分：

- 21 分以上（88%）→ 进 L3
- 19—20 分 → 补练省略与倒装，重测
- 15—18 分 → 重读句式体系，重做本套
- 14 分以下 → 回 L1，词义没稳不要练句式

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 句式认不出 | 「为」当「成为」 | 先看主语是施事还是受事 |
| 认出不会调序 | 知道是倒装，译出来还是原序 | 要求写完必须「读一遍」，读不通就调 |
| 省略不补 | 三个人分不清谁做什么 | 强制先做「谁—做什么—对谁」 |
| 活用当本义 | 「犬坐」译「狗坐着」 | 问「它在动词前，是不是主语」 |

## 下一级预告

L3 从「看得懂」进到「译得准」：不只判断句式，还要在采分点上不失分。句式是 L3 的地基——L2 没稳，L3 的翻译会反复在省略和倒装上丢分。
