# L3 翻译包

**一句话**：翻译不丢分，知道自己每处为什么扣分。

**适用**：初中九年级、高一，或 L2 过关后。

---

## 过关任务

翻译一段 150 字史传或论说（含 3 个关键词、1 处特殊句式、1 处省略），限时 12 分钟。对照参考答案自评。

得分 80% 以上，且扣分处能说出是「词义错」「句式没译出」还是「漏译」，算过关。

## 本级知识清单

### 六字诀（6 条）

- [ ] **留**：人名、地名、官名、年号、书名，原样保留。
- [ ] **删**：发语词（夫、盖）、结构助词、语气词，不译。
- [ ] **换**：古今异义、通假、活用，换成现代说法。
  - 例：兔**走**触株 → 跑·《守株待兔》三下
- [ ] **调**：倒装句调整语序。
  - 例：蒙辞**以军中多务** → 用军中事务多来推托·《孙权劝学》七下
- [ ] **补**：补出省略的主语、宾语、介词。
- [ ] **贯**：通读一遍，语气连贯。最后一步，不能省。

### 采分点三层（3 条）

- [ ] **关键词**：通常是古今异义、活用、通假、多义词。判断方法：按今义译会不会别扭。
  - 例：先帝不以臣**卑鄙** → 身份低微、见识短浅·《出师表》九下
- [ ] **句式**：判断、被动、倒装、省略，各占 1 分。
  - 例：此**诚**危急存亡之秋**也** → 必须译出「是」·《出师表》九下
- [ ] **句意**：整句通顺、逻辑对。最容易拿，也最容易因逐字硬译丢掉。

### 三类固定失分（3 条）

- [ ] **否定词漏译**：不、未、莫、无、非、弗、毋。
  - 例：**不**义而富且贵·《论语》十二章七上
- [ ] **范围词漏译**：皆、咸、悉、尽、俱、独、唯、但、仅、止、徒。
  - 例：村中闻有此人，**咸**来问讯·《桃花源记》八下
- [ ] **省略没补**：主语、宾语、介词。
  - 例：过中不至，太丘舍去，去后乃至·《陈太丘与友期行》七上

**这三类占初中翻译失分的大头**。专项练两周，分数会明显稳。

### 翻译四步（4 条）

- [ ] **圈采分点**：先圈出关键词和句式，再动笔。
- [ ] **逐字落实**：按六字诀处理，不留空白。
- [ ] **补调**：补省略、调语序。
- [ ] **通读**：问三个问题——否定词译了吗？范围词译了吗？谁做的事清楚吗？

### 直译与意译（1 条）

- [ ] **关键词必须直译，修饰性语句可以意译**。考试默认要求直译。

## 必练

- [L3 翻译 10 句](../练习/学生版/L3-翻译.md)，限时 30 分钟，每句 4 分。
- **只圈不译**：拿 10 句，只圈采分点，不翻译。圈准了，翻译自然准。
- **对照扣分**：译完对照答案，只记「扣在哪一层」，不抄答案。
- **专项周**：一周只练否定词，一周只练范围词，一周只练省略。

## 检测

40 分满分：

- 34 分以上（85%）→ 进 L4
- 32—33 分 → 专练三类失分，重测
- 26—31 分 → 重读翻译体系，重做本套
- 25 分以下 → 回 L2

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 只译大意 | 关键词一带而过 | 强制先圈采分点，圈不出不许动笔 |
| 漏否定/范围词 | 意思反了或程度错 | 译完扫原文，圈出所有否定词和范围词 |
| 省略不补 | 译文像另一个人做的事 | 先用括号补，再译 |
| 译完不读 | 句子不通也不改 | 把「读一遍」写进流程，不读不算完成 |

## 下一级预告

L4 从「译得准」进到「读得深」：不只译句子，还要读懂整篇在说什么、为什么这么说，并能用原文证明判断。翻译是 L4 的工具——译不准，概括和比较都会建在沙上。
