# L4 篇章包

**一句话**：读懂整篇在说什么、为什么这么说，能拿原文证明自己的判断。

**适用**：高一、高二，或 L3 过关后。

---

## 过关任务

给一篇 300 字史传（或论说）加两道题：

1. 概括主人公做的一件事及其结果；
2. 给两则材料，比较它们对同一件事的态度。

每题要求引原文。概括准确、两则各引一处证据、能说出相同/相反/补充，算过关。

## 本级知识清单

### 先认文体（9 类，先掌握 4 类）

- [ ] **史传**：人物—事件—评价。抓谁做了什么、结果、作者怎么评。
  - 例：《周亚夫军细柳》——事件「文帝劳军」，评价「此真将军矣」
- [ ] **论说**：论点—论据—方法。抓主张和论证。
  - 例：《劝学》中心「学不可以已」，三个分论点用比喻和对比展开
- [ ] **亭台记**：游踪—景物—情理。写景之后的议论才是重点。
  - 例：《岳阳楼记》两幅景之后落到「先天下之忧而忧」
- [ ] **寓言诸子**：故事—寓意。寓意常在结尾点破。
  - 例：《守株待兔》结尾「皆守株之类也」
- [ ] 其余五类（表、序、书、记、笔记小说）随文补，见 [文体读法](../17-文体读法.md)。

### 概括（3 条）

- [ ] **分层**：按时间、地点、人物变化切成 2—4 层。
- [ ] **提取**：每层找「谁 + 做了什么 + 结果」。
- [ ] **压缩**：去掉修饰，每层一句话。
- 格式：「……（结论）。依据是『……』（原文）。」

### 人物分析（3 条）

- [ ] **言行**：他自己说了什么、做了什么。
  - 例：「介胄之士不拜，请以军礼见」·《周亚夫军细柳》八上
- [ ] **他人反应**：别人怎么看他。
  - 例：文帝「此真将军矣」·同上
- [ ] **作者评价**：作者的判断。
  - 例：「称善者久之」·同上

三层都有，才算分析到位。只有言行是复述，只有评价是贴标签。

### 双材料比较（4 条）

- [ ] **各自取证**：两则分别写「主张 + 依据原句」，不先看结论。
- [ ] **定维度**：比观点、方法、态度，还是对象？
- [ ] **判关系**：相同、相反、补充、递进。
- [ ] **落笔**：先说关系，再各引一句证据。
- 例：《过秦论》归因「仁义不施」，《六国论》归因「赂秦」，角度不同但都指向失道。

### 论证方法（4 条）

- [ ] **比喻**：青，取之于蓝·《劝学》必修上
- [ ] **对比**：古之学者 vs 今之众人·《师说》必修上
- [ ] **举例**：六国赂秦·《六国论》必修下
- [ ] **引用**：引「诗云」·《论语》十二章七上

答法：「用了……论证，把……比作……，说明……」。三层都要有。

### 文化常识（5 类）

- [ ] **官职变动**：拜、除、迁、谪、擢、黜。看点前后文判升降。
  - 例：滕子京**谪**守巴陵郡·《岳阳楼记》九上
- [ ] **科举**：乡试—会试—殿试，解元—会元—状元。
- [ ] **称谓**：谦称（臣、仆、孤）、敬称（陛下、足下、君）。
  - 例：**君**与**家君**期日中·《陈太丘与友期行》七上
- [ ] **礼制**：崩、薨、卒、死；庙号、谥号、年号。
- [ ] **历法地理**：干支、朔望晦、山南水北为阳。
  - 例：壬戌之秋，七月**既望**·《赤壁赋》必修上

判断方法：**先看语境，再调动记忆**。错误选项常是时代错位或对象错位。

## 必练

- [L4 篇章 8 题](../练习/学生版/L4-篇章.md)，限时 35 分钟，每题必须引原文。
- **结构图**：每读一篇，画三到五行的结构图（分层 + 每层一句话）。
- **比较专项**：一次只比一个维度，不要一次比三个。
- **人物三层表**：言行 / 他人反应 / 作者评价，三栏填满才算读完一篇史传。

## 检测

32 分满分：

- 28 分及以上 → 做换材复测，再按真题条件复核是否进入 L5
- 26—27 分 → 专练「概括 + 引证据」格式，重测
- 20—25 分 → 重读文体读法与练习闭环的概括节
- 19 分以下 → 回 L3，读不懂句子谈不上篇章

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 结论空泛 | 「他很勇敢」「都说明了……」 | 强制「一句话结论 + 一句原文」格式 |
| 引了原文不说明 | 只抄句子 | 要求写出「这句怎样支持判断」 |
| 比较只找共同点 | 两则材料说成一样 | 强制填「关系」一栏，必须选相反/补充 |
| 文化常识死背 | 选项一换就错 | 先看语境判时代和对象，再调动记忆 |

## 下一级预告

L5 从「读得深」进到「答得稳」：四类题型有固定步骤，时间分配稳定，错题能归因到具体动作。L4 是「会不会」，L5 是「稳不稳」。
