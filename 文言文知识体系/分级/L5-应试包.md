# L5 应试包

**一句话**：四类题型稳定得分，错题能归因到具体动作，不是「粗心」。

**适用**：高三，或 L4 过关后。

---

## 过关任务

限时 35 分钟做一套高考文言文真题（断句、翻译、概括、简答），按参考答案自评，并填一张错因表。

总分 85% 以上，且每道错题能归因到「词义定错／句式没看出／证据没引／审题漏要求」之一，算过关。

**只做到分数、归因说不清的，不算 L5**。下次换卷还会掉。

## 本级知识清单

### 四类题型规范（4 条）

- [ ] **断句**：先找主谓，再看语气词（也、矣、乎、哉），最后验两种切分。
  - 不确定的地方不硬断，宁可少断一处。
- [ ] **翻译**：先圈采分点（2 关键词 + 1 句式），再动笔；译完读一遍。
- [ ] **概括**：一句话结论 + 一句原文证据。不抄整段，不空谈。
- [ ] **简答**：一问一行，分点写，每个判断后跟一处原文。

### 时间分配（5 条）

以新高考卷文言文约 20 分为例（具体以本地卷为准）：

- [ ] **通读 3 分钟**：只抓人物、时间、事件、观点，不查词。
- [ ] **断句 3 分钟**：先骨架，再虚词，最后验。
- [ ] **概括选择题 3 分钟**：每个选项回原文定位，查人物/时间/范围/原因是否被换。
- [ ] **翻译 8—10 分钟**：两句各 4—5 分钟，先圈再译。
- [ ] **简答 5 分钟**：先结论后证据。

**总原则**：宁可翻译少花两分钟，也要把概括选择题逐一定位。翻译是会多少拿多少，选择题是定位准就全对。

### 错因归因（5 类）

错题只归到这五类，不许写「粗心」「没读懂」：

- [ ] **词义定错**：关键词译错 → 回 L1/L3
- [ ] **句式没看出**：被动、倒装、省略没识别 → 回 L2
- [ ] **漏译**：否定、范围、程度词漏掉 → 回 L3
- [ ] **证据没引**：概括题只给结论 → 回 L4
- [ ] **审题漏要求**：问「原因」答「表现」，问「两则」答「一则」→ 练审题

### 卷面表达（3 条）

- [ ] **分点写**：简答题用「①②③」，一问一行。
- [ ] **先结论后证据**：不要先铺陈再给结论。
- [ ] **不写废话**：「我认为」「由此可见」这类词能省就省，阅卷看采分点。

## 必练

- [L5 卷一 5 题](../练习/学生版/L5-应试.md)，限时 35 分钟。
- 隔 2—3 天做 [L5 卷二 8 题](../练习/学生版/L5-应试-平行卷.md)，限时 40 分钟，同动作换材料。
- 两卷都稳了，按 [真题选卷与改编指南](../练习/真题选卷与改编指南.md) 选本地真题，**每周 1—2 套**，严格限时。
- **错因表**：每套卷填一张，只填五类归因，一周统计一次哪类最多。
- **复测**：同类错因连续三次不重复，才算解决。

## 检测

20 分满分：

- 18—20 分 → 课内练习完成，换真题复核时间和错因
- 17 分 → 专项补最弱一类，一周后复测
- 15—16 分 → 回 L3 或 L4 补对应缺口
- 14 分以下 → 按归因回对应级别，不要继续刷套卷

卷二 30 分制：26—30 换材稳定 → 接真题；23—25 补最弱一类；19—22 回 L3 或 L4；18 以下按归因回级。分数段与两卷动作对照见 [卷二教师版](../练习/教师版/L5-应试-平行卷-答案.md)。

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 断句凭语感 | 不找主谓和语气词 | 强制先圈人名、找动词，再断 |
| 翻译求快 | 关键词不落实 | 先圈采分点，圈不出不许写 |
| 概括答成翻译 | 整段抄原文 | 强制「一句话 + 一句证据」格式 |
| 时间不够 | 最后一道简答没写完 | 按时间表掐表练，先保选择题 |
| 归因笼统 | 「粗心」「没读懂」 | 只许五类，写不出就是没归因 |

## 三条判据（比分数重要）

1. 四类题型都有稳定的操作步骤，不靠临场感觉。
2. 错题能归因到具体动作，不是「粗心」。
3. 同一类错因连续三次不再重复。

三条都做到才算 L5。只做到「分数够了」但归因说不清，下一次换卷还会掉。

## 到这里之后

L5 不是终点。往后是「保持」：每周一套卷维持手感，错因表继续记，直到同类错因彻底消失。真正的稳定不是「这次考好了」，是「换十套卷都不掉」。
