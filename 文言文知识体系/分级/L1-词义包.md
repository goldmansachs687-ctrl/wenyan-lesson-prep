# L1 词义包

**一句话**：遇到没学过的词，有办法猜，而且猜得有理有据。

**适用**：小学五、六年级，初一，或 L0 过关后。

---

## 过关任务

给一段 60 字小古文（含 2 个古今异义、1 个通假），解释 5 个加点词，每个词写出「本句义 + 判断依据」。

5 个词义对 4 个以上，且至少 3 个能说出依据，算过关。

## 本级知识清单

### 猜词四法（4 条）

- [ ] **组词法**：用这个字组一个现代词，看是否讲得通。
  - 例：溺而不**返** → 返回·《精卫填海》四上
- [ ] **换词法**：换一个意思相近的字，读一遍。
  - 例：兔**走**触株 → 跑·《守株待兔》三下
- [ ] **上下文**：看前后句的逻辑。
  - 例：**冀**复得兔，后文说「兔不可复得」，所以是「希望」·《守株待兔》三下
- [ ] **成语法**：想一个含这个字的成语。
  - 例：**顾** → 左顾右盼 → 看、回头看·《狼》七下

### 古今异义（4 类）

- [ ] **词义扩大**：专指变泛指。江、河原专指长江、黄河。
- [ ] **词义缩小**：泛指变专指。金原泛指金属。
- [ ] **词义转移**：所指对象换了。走＝跑，去＝离开，汤＝热水。
  - 例：太丘舍**去** → 离开·《陈太丘与友期行》七上
- [ ] **感情色彩变化**：褒贬变了。卑鄙原指身份低微，今指品质恶劣。

**判断方法**：把今义代进去，句子讲不通或别扭，就是古今异义。

### 通假三步（3 条）

- [ ] **按本字讲不通**：用本义解释，句子别扭。
- [ ] **读音相同或相近**。
- [ ] **换成借字后通顺**。
  - 例：甚聪**惠** → 通「慧」，聪明·《杨氏之子》五下

三步同时满足才是通假。「走」不是通假，是词义转移——按「跑」讲得通，只是今义变了。

### 一词多义（2 条）

- [ ] **看搭配定项**：后面接人、接物、接地点，义项不同。
  - 例：**顾**野有麦场（看）／三**顾**臣于草庐（拜访）·《狼》《出师表》
- [ ] **课内同形句对照**：找学过的同字句比较，最可靠。

### 虚词初识（4 个）

本级只认 4 个，各 1—2 种用法：

- [ ] **之**：代词（他/它）、助词（的）
- [ ] **其**：他的、其中的
- [ ] **而**：承接、转折
- [ ] **以**：用、因为

## 必练

- [L1 词义 12 题](../练习/学生版/L1-词义.md)，限时 25 分钟。
- 每天 5 个词，只做三件事：找一句课内原句、说出本句义、说出依据。
- 做「古今异义卡」：正面原句，背面今义和古义，一周攒 10 张。

## 检测

24 分满分：

- 20 分以上（83%）→ 进 L2
- 18—19 分 → 再练一周通假三步，重测
- 14—17 分 → 重读实词体系前三节，重做本套
- 13 分以下 → 回 L0

## 常见卡点

| 卡点 | 表现 | 怎么办 |
| --- | --- | --- |
| 今义覆盖 | 「走」答走路、「去」答前往 | 把原句和今义放在一起读，让学生自己发现讲不通 |
| 通假看不出 | 按本字硬解，句子不通也不回头 | 教「三步」，每次通假都让他说一遍三步 |
| 多义只记一个 | 换个句子就套错 | 做「同字卡」，一字收 3—5 句 |
| 只会答词义不会说依据 | 靠背答案 | 依据也算分，说不出的最多给一半 |

## 下一级预告

L2 从「词」进到「句」：看得出一句话的骨架，知道哪里省略了、哪里倒装了。本级词义没稳就上 L2，会在句式上反复卡住——因为句式判断常常要先看懂词。
