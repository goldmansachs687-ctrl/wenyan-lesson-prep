# 黄金备课用例

用来验收「知识体系 + Skill」能不能真的支撑一节课。三条真实请求，每条列明**必须出现**和**禁止出现**，老师照着勾，就能判断这次备课是否合格。

不要用「写得不错」当标准。只看两条：目标能不能观察、引文能不能回查。

## 用例一｜七年级《狼》，L2，一课时

**老师这样说**：

```text
用文言文备课 Skill，用我的《狼》资料备七年级一课时，只练「其一犬坐于前」的名词作状语。
给课堂步骤、一个追问、三道递进练习，学生题和教师答案分开。
```

**必须出现**：

- [ ] 目标写成可观察的产出：「能说出『犬』在这里是『像狗一样』，并指出它在动词『坐』前，所以是状语」
- [ ] 先查了老师自己的《狼》原稿或篇目笔记，注明来源
- [ ] 判断步骤：名词在动词前 → 表方式/状态 → 状语（不是「狗坐着」）
- [ ] 一个追问，能听出学生是否真懂，例如「『犬坐』能不能改成『狗坐』？为什么」
- [ ] 三道题分层：基础（认出状语）、应用（译句）、迁移（换一篇里的名词作状语）
- [ ] 学生版只有题干和作答要求
- [ ] 教师版有参考答案、可接受答法、采分点、错因预判
- [ ] 引文与老师课本一致

**禁止出现**：

- [ ] 目标写成「掌握词类活用」这类不可观察的表述
- [ ] 一节课讲六种活用（名作动、名作状、形作名、使动、意动、动作名）
- [ ] 学生版里出现「采分点」「参考答案」「错因预判」
- [ ] 编造课内没有的例句而不标出处
- [ ] 把「犬坐」译成「狗坐着」

**判**：8 条必须项做到 6 条以上、禁止项全部未出现，算合格。

## 用例二｜九年级中考复习，L3→L4，一课时

**老师这样说**：

```text
用文言文备课 Skill，我班翻译总在否定词和范围词上丢分。用课内材料排一节课，
只练这两类漏译，配一道课外迁移题。
```

**必须出现**：

- [ ] 先确认学情（「翻译总在否定词和范围词上丢分」），不是泛泛复习翻译
- [ ] 目标聚焦两类失分，不扩展到「句式」「活用」
- [ ] 课内例句至少来自两篇不同课文，标出处
- [ ] 教「译完扫一遍原文，圈出否定词/范围词」这个可操作动作
- [ ] 一道课外迁移题，材料完整、有出处或标明「自拟」
- [ ] 学生版与教师版分开
- [ ] 教师版按「关键词/句式/句意」给分，并标出漏译扣哪一项

**禁止出现**：

- [ ] 把「翻译」整个专题铺开讲（六字诀全讲一遍）
- [ ] 只给答案不讲「怎么查漏」
- [ ] 课外材料来源不明却当作真题
- [ ] 教师版把整句判错，不指出漏了哪个词

**判**：7 条必须项做到 5 条以上、禁止项全部未出现，算合格。

## 用例三｜高三，L5，双材料比较

**老师这样说**：

```text
用文言文备课 Skill，备一节高三文言文，练双材料比较：两则材料对「孝」的态度。
要教学生怎么各自取证、怎么判断关系。给一道同类型的迁移题。
```

**必须出现**：

- [ ] 两则材料都完整给出，标出处（课内或注明「课外」）
- [ ] 教「先各自写主张 + 依据原句，再判断关系（相同/相反/补充/递进）」这个流程
- [ ] 强调「人物的观点」与「作者的议论」要分开
- [ ] 教师版给两则各自的参考答案，再给关系判断
- [ ] 迁移题同类型（也是双材料比较），不是换成翻译题
- [ ] 给分按「观点 + 证据 + 关系」三层，不按「字数」

**禁止出现**：

- [ ] 直接给结论，不教取证过程
- [ ] 两则材料只讲共同点，不讲差异
- [ ] 把「孝」的讨论变成文化常识背诵
- [ ] 迁移题与所教动作不一致
- [ ] 用「言之成理即可」代替采分点

**判**：6 条必须项做到 4 条以上、禁止项全部未出现，算合格。

## 怎么用这三条

1. **换模型/换版本时跑一次**：Codex 升级、Skill 改版后，用用例一跑一遍，看是否还达标。
2. **老师验收时跑一次**：拿到新包，按用例一备课，勾完表再决定是否给学生用。
3. **发现问题就回改**：如果某条必须项反复做不到，说明 SKILL.md 或知识体系那一节写得不够清楚，改文档，不要只怪模型。

## 三条用例覆盖了什么

| 用例 | 能力级 | 主要考 |
| --- | --- | --- |
| 一 | L2 | 单点突破、目标可观察、学生版/教师版分离 |
| 二 | L3→L4 | 按失分备课、可操作动作、迁移题同类型 |
| 三 | L5 | 双材料取证、关系判断、评分分层 |

三条都没覆盖「小学低段」和「整本书/单元整体」。需要时按同样格式补，判断标准不变：**目标可观察、引文可回查、学生版不泄题**。
