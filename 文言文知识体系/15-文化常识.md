# 文化常识

文化常识不是背词典，是**放回语境判断**。高考这道题的错误选项，九成是「时代错位」或「对象错位」——把唐朝的制度安到汉朝，把诸侯的礼用到天子身上。所以先看语境，再调动记忆。

按四类积累就够用：**官职、科举、称谓、礼制历法**。

## 一、官职变动（史传必考）

| 词 | 意思 | 课内例 |
| --- | --- | --- |
| 拜 | 授官 | 拜臣郎中·《陈情表》选必下 |
| 除 | 授职 | 寻蒙国恩，除臣洗马·《陈情表》选必下 |
| 迁 | 调动，多指升职 | 迁为太史令（课外） |
| 左迁 | 降职 | 闻王昌龄左迁龙标（课外） |
| 谪 | 贬官 | 滕子京谪守巴陵郡·《岳阳楼记》九上 |
| 贬 | 降职 | 贬连州刺史（课外） |
| 擢 | 提拔 | 擢为后将军（课外） |
| 徙 | 调职 | 徙为太常（课外） |
| 黜 / 罢 / 免 | 罢免 | 黜官（课外） |
| 征 / 辟 | 征召 | 连辟公府不就（课外） |
| 领 | 兼任（较低官职） | 领行营节度使（课外） |
| 权 | 暂代 | 权知开封府（课外） |
| 摄 | 代理 | 摄监察御史（课外） |
| 知 | 主持 | 知开封府（课外） |

**判断升还是降**：看前后文有没有「贬、谪、左迁、坐」这些字；看这个人之前之后的态度（「谢恩」多半是升，「郁郁」多半是降）。

**易错**：「迁」不一定是升。「左迁」是降，「迁谪」连用是贬官。看到「迁」先别急着判升。

## 二、科举

| 阶段 | 考中称 | 说明 |
| --- | --- | --- |
| 院试 | 秀才（生员） | 县级 |
| 乡试（秋闱） | 举人 | 省级，第一名称解元 |
| 会试（春闱） | 贡士 | 礼部主持，第一名称会元 |
| 殿试 | 进士 | 皇帝主持，第一名称状元，二名榜眼，三名探花 |

**相关词**：及第（考中）、落第（没考中）、同年（同榜）、座主（主考官）、门生（被录取者）。

**易错**：「进士」是殿试录取后的身份，不是「进京考试的士子」。乡试第一是「解元」，不是「会元」。

## 三、称谓

| 类别 | 词 | 说明 |
| --- | --- | --- |
| 谦称 | 臣、仆、愚、鄙人、不才、寡人、孤、不谷 | 寡人、孤是王侯自称 |
| 敬称 | 陛下、殿下、阁下、足下、君、公、子、先生、夫子 | 「陛下」专称皇帝 |
| 贱称 | 竖子、小子 | 骂人 |
| 自称 | 称名 | 对人称自己的名，表谦 |
| 称人 | 称字、称号、称官名、称籍贯 | 不称名，表敬 |
| 亲属 | 家君（谦，称自己父亲）、尊君（敬，称对方父亲） | |

课内例：`君与家君期日中`·《陈太丘与友期行》七上——「君」是敬称对方，「家君」是谦称自己父亲。

课内例：`孤岂欲卿治经为博士邪`·《孙权劝学》七下——「孤」是王侯自称。

**易错**：「家君」是「我的父亲」，「尊君」是「你的父亲」，方向别搞反。

## 四、礼制与丧葬

| 词 | 对象 |
| --- | --- |
| 崩 | 帝王死 |
| 薨 | 诸侯、高官死 |
| 卒 | 大夫死 |
| 死 | 庶人死 |
| 殁 | 通称死亡 |
| 期年 | 满一年（服丧） |
| 功服 | 大功九月、小功五月（丧服） |
| 庙号 | 帝王死后在太庙立室奉祀的名号，如「太祖」「太宗」 |
| 谥号 | 死后依生平评定，如「文正」「武穆」 |
| 年号 | 帝王纪年，如「庆历」「元丰」 |

**易错**：庙号、谥号、年号三者别混。「庆历」是年号，「文正」是谥号，「太祖」是庙号。

## 五、历法与时间

| 词 | 意思 |
| --- | --- |
| 干支纪年 | 天干（甲乙丙丁…）配地支（子丑寅卯…），六十年一轮 |
| 朔 | 农历初一 |
| 望 | 农历十五 |
| 既望 | 农历十六 |
| 晦 | 农历月末 |
| 孟仲季 | 每季三个月，依次为孟、仲、季 |
| 五更 | 夜间分五段，一更约两小时 |
| 时辰 | 子丑寅卯辰巳午未申酉戌亥，各两小时 |

课内例：`壬戌之秋，七月既望`·《赤壁赋》必修上——「壬戌」是干支纪年，「既望」是十六。

**易错**：「既望」是十六，不是十五。「望」才是十五。

## 六、地理

| 词 | 意思 |
| --- | --- |
| 山南水北为阳 | 如「汉阳」在汉水北岸 |
| 山北水南为阴 | 如「汉阴」在汉水南岸 |
| 江左 / 江东 | 长江下游以东 |
| 江右 / 江西 | 长江下游以西 |
| 山东 | 崤山以东（不是今山东省） |
| 关中 | 函谷关以西 |
| 郡、州、县 | 行政区划层级，各代不同 |

课内例：`指通豫南，达于汉阴`·《愚公移山》八上——「汉阴」是汉水南岸。

**易错**：「山东」在先秦秦汉指崤山以东，和今天的山东省不是一回事。

## 怎么做文化常识题

1. **先读语境**：这个官职/称谓/礼制出现在什么场景里？人物的身份是什么？
2. **查时代**：这个制度是哪个朝代的？选项说的朝代对不对？（最常见的错法）
3. **查对象**：这个礼制用在谁身上？天子、诸侯、大夫、庶人不能混。
4. **最后才调动记忆**：前两步能排掉大部分错误选项。

**不要**一上来就背。文化常识题考的是「能不能判断」，不是「背了多少」。

积累方法：史传每读一篇，把出现的官职词抄进「官职表」，按「授官／升／降／调／免」五栏分类，一学期就能攒够常用词。
