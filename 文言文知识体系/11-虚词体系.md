# 虚词体系（18 个）

文言虚词一共就这 18 个：**而、何、乎、乃、其、且、若、所、为、焉、也、以、因、于、与、则、者、之**。

学虚词只有一条路：**不看定义，看它连接什么、指代谁**。同一个「而」，在「折颈而死」里连接两个先后动作，在「而身为宋国笑」里连接相反的结果——先判断关系，再套术语。术语答错不扣分，关系判断错才丢分。

本文件的例句全部取自课内正文，标了篇目和学段，可回 `文言文语料库` 核对。标「课外」的是课内没有合适例句、但考试常考的用法。

## 18 个虚词速查

| 虚词 | 最常见用法（按频率） | 一句话判断 |
| --- | --- | --- |
| 之 | 代词 / 的 / 取消独立性 / 宾语前置标志 / 往 | 后面跟着名词→「的」；后面是动词且前面有主语→取消独立性 |
| 而 | 承接 / 转折 / 修饰 / 并列 / 递进 | 两侧动作先后→承接；两侧意思相反→转折；后者是前者的状态→修饰 |
| 以 | 用拿 / 因为 / 凭借 / 来 / 认为 | 后面是名词→介词；后面是动词→连词「来」 |
| 其 | 他的 / 他 / 那 / 难道、大概 | 后面是名词→代词；句首+语气→副词 |
| 于 | 在 / 到 / 向 / 比 / 被 | 看后面跟的是地点、对象还是比较对象 |
| 为 | 做 / 是 / 成为 / 替 / 被 | 读 wéi 多是动词，读 wèi 多是介词 |
| 者 | ……的人 / 判断标志 / 定语后置 / 停顿 | 跟在动词后→的人；跟在名词后→停顿 |
| 也 | 判断 / 解释 / 疑问 / 句中停顿 | 句末→语气；句中→停顿 |
| 所 | 所+动词 / 为…所… / 所以 | 后面一定是动词 |
| 则 | 就 / 却 / 就是 / 如果 | 前后是条件结果→就；前后相反→却 |
| 乃 | 于是 / 才 / 竟然 / 是 | 前后是先后动作→于是；出乎意料→竟然 |
| 因 | 于是 / 凭借 / 沿袭 | 后面是动作→于是；后面是名词→凭借 |
| 与 | 和 / 给 / 赞同 / 通「欤」 | 连接两个名词→和；句末→欤 |
| 且 | 并且 / 尚且 / 将要 | 后面是数字或时间→将要；「且…况…」→尚且 |
| 若 | 像 / 你 / 如果 / 比得上 | 后面是名词→像；句首→如果 |
| 何 | 什么 / 为什么 / 怎么 / 多么 | 后面是名词→什么；后面是动词→为什么 |
| 乎 | 吗 / 啊 / 于 | 句末→语气；动词后接地点→于 |
| 焉 | 于此 / 语气 / 哪里 | 句末且前有动作→于此；句末无实义→语气 |

## 高频四词：之、而、以、其

### 之

| 用法 | 标志 | 课内例 |
| --- | --- | --- |
| 代词，他/它/这件事 | 前面有动词 | 光持石击瓮破**之**（瓮）·《司马光》三上 |
| 助词，的 | 后面是名词 | 炎帝**之**少女·《精卫填海》四上 |
| 取消句子独立性 | 主语+之+谓语，整句作成分 | 予独爱莲**之**出淤泥而不染·《爱莲说》七下 |
| 宾语前置标志 | 「何……之有」 | 何陋**之**有·《陋室铭》七下 |
| 动词，往、到 | 后面接地点 | 已而**之**细柳军·《周亚夫军细柳》八上 |
| 音节助词，无义 | 时间词后 | 久**之**，目似瞑·《狼》七下 |

**判断三步**：① 后面是名词吗？是→「的」。② 前面是动词、后面也是动词？→ 代词或取消独立性。③ 后面是地点？→ 动词「往」。

**易错**：「何陋之有」的「之」不是「的」，是宾语前置标志，正常语序是「有何陋」。

### 而

| 用法 | 标志 | 课内例 |
| --- | --- | --- |
| 承接 | 两个动作先后发生 | 兔走触株，折颈**而**死·《守株待兔》三下 |
| 转折 | 前后意思相反 | 兔不可复得，**而**身为宋国笑·《守株待兔》三下 |
| 并列 | 两个同类动作或性质 | 敏**而**好学·《古人谈读书》五上 |
| 修饰 | 后者是前者的状态/方式 | 康肃笑**而**遣之·《卖油翁》七下 |
| 递进 | 后者比前者更进一步 | 饮少辄醉，**而**年又最高·《醉翁亭记》九上 |

**判断两步**：① 两侧能不能调换顺序？不能→承接。② 两侧意思相反吗？是→转折。③ 后者是不是在描述前者怎么做？是→修饰。

**易错**：「折颈而死」不是转折，是承接——先折颈，后死。「而」的四种关系里，承接和修饰最容易混：承接是「先 A 后 B」，修饰是「B 是 A 的方式」。

### 以

| 用法 | 标志 | 课内例 |
| --- | --- | --- |
| 介词，用、拿 | 后面是工具 | **以**钱覆其口·《卖油翁》七下 |
| 介词，因为 | 后面是原因 | 不**以**物喜，不以己悲·《岳阳楼记》九上 |
| 介词，凭借 | 后面是身份/条件 | **以**我酌油知之·《卖油翁》七下 |
| 连词，来、以便 | 连接两个动作，后者是目的 | 练囊盛数十萤火**以**照书·《囊萤夜读》四下 |
| 动词，认为 | 后面接一个判断 | 我**以**日始出时去人近·《两小儿辩日》六下 |

**判断两步**：① 后面是名词？→ 介词（用/因为/凭借，看名词性质）。② 后面是动词？→ 连词「来」。

**易错**：「以」和「以为」要分开看。「自以为大有所益」是「自＋以为」；「以我酌油知之」是「以＋我」。

### 其

| 用法 | 标志 | 课内例 |
| --- | --- | --- |
| 代词，他的/它的 | 后面是名词 | 因释**其**耒而守株·《守株待兔》三下 |
| 代词，他/它 | 前面有动词 | 见**其**发矢十中八九·《卖油翁》七下 |
| 指示代词，那、其中 | 「其一人」「其一」 | **其**一人专心致志·《学弈》六下 |
| 副词，难道、大概 | 句首，表反问或推测 | **其**真无马邪？**其**真不知马也·《马说》八下 |

**判断两步**：① 后面是名词？→ 代词「他的」。② 句首且句末有「邪/也/乎」？→ 语气副词。

**易错**：「其真无马邪？其真不知马也」两个「其」都是语气副词，前一个「难道」，后一个「大概」，不是代词。

## 高频五词：于、为、者、也、所

### 于

| 用法 | 课内例 |
| --- | --- |
| 在 | 群儿戏**于**庭·《司马光》三上 |
| 到 | 女娃游**于**东海·《精卫填海》四上 |
| 向 | 宋君令人问之**于**丁氏·《穿井得一人》七上 |
| 比 | 所欲有甚**于**生者·《鱼我所欲也》九下 |
| 被 | 不拘**于**时·《师说》必修上 |

**判断**：后面是地点→在/到；后面是人→向/对；后面是比较对象（有「甚、过」）→比；动词是「受、拘、制」→被。

### 为

| 用法 | 读音 | 课内例 |
| --- | --- | --- |
| 做、干 | wéi | 为人谋而不忠乎·《论语》十二章七上 |
| 是 | wéi | 知之为知之·《古人谈读书》五上 |
| 成为 | wéi | 故**为**精卫·《精卫填海》四上 |
| 替、给 | wèi | **为**设果·《杨氏之子》五下 |
| 被 | wéi | 身**为**宋国笑·《守株待兔》三下 |
| 为了 | wèi | **为**宫室之美·《鱼我所欲也》九下 |

**判断**：先看读音。wéi → 动词（做/是/成为）；wèi → 介词（替/为了）。再看后面：接「所」或前面有「身、受」→ 被。

### 者

| 用法 | 课内例 |
| --- | --- |
| ……的人/事/物 | 宋人有耕**者**·《守株待兔》三下 |
| 判断句标志（……者，……也） | 弈秋，通国之善弈**者**也·《学弈》六下 |
| 定语后置标志 | 马之千里**者**·《马说》八下 |
| 句中停顿 | 北山愚公**者**，年且九十·《愚公移山》八上 |

**判断**：跟在动词后→「……的人」；跟在名词后且句中有「也」→判断；「之……者」→定语后置。

### 也

| 用法 | 课内例 |
| --- | --- |
| 判断句末 | 陈胜**者**，阳城人**也**·《陈涉世家》九下 |
| 解释、陈述语气 | 师**者**，所以传道受业解惑**也**·《师说》必修上 |
| 疑问、反问 | 安求其能千里**也**·《马说》八下 |
| 句中停顿 | 其闻道**也**固先乎吾·《师说》必修上 |

**判断**：句末→语气（判断/解释/疑问）；句中→停顿。看到「……者，……也」直接判判断句。

### 所

| 用法 | 课内例 |
| --- | --- |
| 所+动词＝名词性短语 | 好书画，**所**宝以百数·《书戴嵩画牛》六上 |
| 为……所……表被动 | 其印**为**予群从**所**得·《活板》七下 |
| 所以＝用来/原因 | **所以**传道受业解惑也·《师说》必修上 |
| 所谓 | **所谓**伊人，在水一方·《诗经》（课外） |

**判断**：「所」后面一定是动词，这是最硬的标志。看到「为……所……」直接判被动。

## 中频四词：则、乃、因、与

### 则

| 用法 | 课内例 |
| --- | --- |
| 就、那么 | 学而不思**则**罔·《论语》十二章七上 |
| 却 | 欲速**则**不达·《论语》（课外） |
| 就是 | 此**则**岳阳楼之大观也·《岳阳楼记》九上 |
| 如果 | 入**则**无法家拂士·《生于忧患，死于安乐》八上 |

**判断**：前后是条件结果→就；前后相反→却；「此则」→就是；「则」在句首表假设→如果。

### 乃

| 用法 | 课内例 |
| --- | --- |
| 于是、就 | **乃**取一葫芦置于地·《卖油翁》七下 |
| 才 | **乃**悟前狼假寐·《狼》七下 |
| 竟然 | **乃**不知有汉，无论魏晋·《桃花源记》八下 |
| 是 | 当立者**乃**公子扶苏·《陈涉世家》九下 |

**判断**：前后是先后动作→于是；动作完成之后才发生→才；出乎意料→竟然；「乃」后接人名/身份→是。

### 因

| 用法 | 课内例 |
| --- | --- |
| 于是、就 | **因**释其耒而守株·《守株待兔》三下 |
| 凭借、趁着 | 未若柳絮**因**风起·《咏雪》七上 |
| 沿袭 | **因**遗策·《过秦论》选必中 |

**判断**：后面是动作→于是；后面是名词（风、势）→凭借。

### 与

| 用法 | 课内例 |
| --- | --- |
| 和、跟 | 尝**与**诸小儿遊·《王戎不取道旁李》四上 |
| 赞同 | 吾**与**点也·《子路、曾皙、冉有、公西华侍坐》必修下 |
| 通「欤」，语气词 | 为是其智弗若**与**·《学弈》六下 |

「与」作「给」多见于篇名和书信，如《与朱元思书》即「给朱元思的信」，句中不常单用。

**判断**：连接两个名词→和；后面是「书、信」→给；句末→通「欤」。

## 必考五词：且、若、何、乎、焉

### 且

| 用法 | 课内例 |
| --- | --- |
| 并且、而且 | **且**壮士不死即已·《陈涉世家》九下 |
| 尚且 | **且**欲与常马等不可得·《马说》八下 |
| 将要 | 年**且**九十·《愚公移山》八上 |

**判断**：后面是数字/时间→将要；「且……况/安……」→尚且；连接两个分句→并且。

### 若

| 用法 | 课内例 |
| --- | --- |
| 像、好像 | 未**若**柳絮因风起·《咏雪》七上 |
| 比得上 | 孰**若**孤·《孙权劝学》七下 |
| 你 | **若**为佣耕·《陈涉世家》九下 |
| 如果 | **若**跨有荆、益·《隆中对》（课外） |

**判断**：后面是名词→像；「孰若」→比得上；后面是「为」+身份→你；句首引出假设→如果。

### 何

| 用法 | 课内例 |
| --- | --- |
| 什么 | **何**陋之有·《陋室铭》七下 |
| 为什么 | **何**苦而不平·《愚公移山》八上 |
| 怎么 | **何**能尔·《饮酒》（课外） |
| 多么 | 水**何**澹澹·《观沧海》（课外） |

**判断**：后面是名词→什么；后面是动词→为什么/怎么；「何……之有」→宾语前置。

### 乎

| 用法 | 课内例 |
| --- | --- |
| 吗、呢 | 不亦说**乎**·《论语》十二章七上 |
| 啊、呀 | 技盖至此**乎**·《庖丁解牛》必修下 |
| 于（介词） | 生**乎**吾前·《师说》必修上 |

**判断**：句末→语气词；动词后接时间/地点→「于」。

### 焉

| 用法 | 课内例 |
| --- | --- |
| 兼词，于此/于之 | 三人行，必有我师**焉**·《论语》十二章七上 |
| 语气词 | 可远观而不可亵玩**焉**·《爱莲说》七下 |
| 哪里 | **焉**置土石·《愚公移山》八上 |

**判断**：句末且前面是动作→「于此」；句末无实义→语气词；句首/动词前→哪里。

## 怎么练

1. **一次只练一个词**。把 18 个词的表背下来没用，挑「之」或「而」，找 10 个课内句子，逐句判断关系，再对照本表。
2. **练「圈两侧」**。拿到句子先圈虚词左右各一个词，再判断关系。不要先想术语。
3. **错题只记句子**。错了就把原句抄下来，写明「我以为是什么关系，实际是什么关系」，不抄定义。
4. **迁移检验**。用没学过的课外句子测同一个词，能判断对才算会。
