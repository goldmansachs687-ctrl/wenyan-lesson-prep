# 知识库覆盖与缺口

核对范围为当前随 Skill 分发的教材目录、正文、辞书、课堂卡与训练资料。课文按学制、册次和版次计收录位置，同一篇可重复计入。

| 范围 | 当前覆盖 | 使用边界 |
| --- | --- | --- |
| 统编六三义务教育 | 一至九年级 18 册，60 个位置（小学 16、初中 44），保留换版前的部分位置 | 部分正文沿用古籍选段或公开校录；教材换版时核对页码、异文和选段。 |
| 统编五四义务教育 | 一至九年级 18 册，57 个位置（小学 10、初中 47）；六年级按初中计 | 56 个位置用共享古文底本参照；四下、五下、九下按已核公开旧版。 |
| 统编高中 | 必修与选择性必修 5 册，36 个位置 | 同名篇目先核教材册次和节选范围；底本可用于备课对读。 |
| 离线辞书 | 《康熙字典》46,890 个字头、《说文解字》9,815 个字头、中文维基词典选辑 5,412 个词头 | 三库有重合。字头与文言标签用于查出处和候选义，定释义需回到本课语境。 |
| 课内教学 | 18 个虚词有可查例句，44 张课堂知识卡；六级学习包覆盖 22 项能力 | 当前有 49 个收录位置命中课堂卡原句；地图按底本逐一对读。 |
| 中高考复习 | 有专题复习、错因讲评方法；L0—L5 共 63 题（L5 两套卷：卷一 5 题 + 换材卷 8 题，同动作换材料）、六级换材复测与 [真题选卷与改编指南](练习/真题选卷与改编指南.md) | 包里**不收录高考真题原文**：权利分属各机构、卷型逐年变、动作需换材验证。各地卷型、年度真题和评分口径以当地材料为准；教师评分表可结合课堂调整。 |

教材的 153 个收录位置均有原文参照。[篇目地图](20-篇目地图.md)分别列出据教材核对的选段、古籍底本、公开课文整理本和共享底本。[六三与高中目录](../文言文语料库/教学参考/统编课内/课内目录.md)及[五四目录](../文言文语料库/教学参考/统编课内/五四学制课内目录.md)附册次与出处。目录收录独立文言课文及有题名的文言选段，古诗词曲、识字韵文和语文园地零散引文请通过教材入口补查。

**两处数字口径**：篇目位置 96 指六三义务教育 60 + 高中 36，另有五四学制 57 个，合计 153；同一篇按学制、册次、版次重复计入，去重后的实际篇目数少于 153。字典数在 [语料库目录](../文言文语料库/语料库目录.md) 按「条／义项」计（康熙 47,030、说文 9,833、维基 7,608），本表按「字头／词头」计（46,890 / 9,815 / 5,412），口径不同，不是数据不一致。

结合[字典来源](../文言文语料库/字书/扩充/SOURCES.md)查看原字和书证，结合[中高考专题](../文言文语料库/教学参考/复习/中考高考文言文复习.md)选择地区和题型。分级学习、练习和复测由[分级索引](分级/README.md)进入。

在项目根目录运行以下命令可重新核对公开包的目录、引文、查询和分级流程。

```powershell
python -B -X utf8 验收备课.py --read-only
```

在可写的终端运行完整模式（去掉 `--read-only`），还可用临时样例检查教师资料导航。
