## 怎么用

**老师**：

1. 先按 [诊断](../02-诊断与定级.md) 定级，或直接用本级题库做入门测。
2. 只发学生版。答案与采分点在教师版，不要一起发。
3. 批改按教师版的「错因预判」归因，不写「粗心」。
4. 讲评按 [练习与讲评闭环](../30-练习与讲评闭环.md) 的四步走。

**学生**：

1. 按定级结果选一套，限时做，不查字典。
2. 做完自己对教师版批改，只记错因，不抄答案。
3. 完成补练后换材料复测。只做同一级的[学生版复测](学生版/分级复测.md)，由老师对照[教师评分](教师版/分级复测-答案.md)核对。

## 评分与升级

- 专项训练按各级教师版的评分档讲评。升级要看对应的能力过关任务及换材复测结果。
- 未通过时，从具体错因回到当级的知识或阅读步骤，再换同级材料验证。
- L5 的课内复测通过后，用限时高考真题核对得分、用时和错因。

## 材料说明

- L1—L4 全部取自统编课内篇目，材料后标了出处，可回 `文言文语料库/教学参考/统编课内/` 核对。
- 题干引文保持底本原字形。老师课堂用字如与底本不同（如「霪雨／淫雨」），以课本为准，答案里标了可接受的等价说法。
- L5 用课内长篇节选做高考题型，属于「课内迁移」，不是押题。真题请按当地卷另行选用。
