# 文言文备课 Skill

给小学、初中和高中语文教师查课文、找字词书证、做教案和分层练习。知识体系按阅读能力从 L0 认读排到 L5 应试，老师可以据学生作答选课、选题和复测。

## 老师第一次怎么用

在已打开的 DeepSeek Harness 里新建对话，复制下面这段话。Harness 会尝试下载、配置并试备一节课。

```text
请在当前工作区下载并配置文言文备课 Skill，然后帮我试备一节课。
仓库 https://github.com/goldmansachs687-ctrl/wenyan-lesson-prep
请获取 main 分支的完整项目，加载 .agents/skills/wenyan-lesson-prep/SKILL.md，并核对同一目录下的课文、字典和分级题库能否读取。
请查七年级《孙权劝学》的原文和出处，按 L2 句法层备一节 20 分钟小课，重点讲「与蒙论议，大惊曰」省略了谁。给我教案、学生练习、换材料复测和单独的教师答案。
最后告诉我项目放在哪里、是否加载成功，以及下次怎么调用。
```

下次备课可以直接说「用文言文备课 Skill」，再告诉它年级、篇目、学生卡点和想要的材料。[完整提示词、日常用法及常见问题](开始使用.md)

## 知识体系

| 能力级 | 训练重点 |
| --- | --- |
| L0 认读 | 朗读停顿、复述事件、找简单指代 |
| L1 词义 | 通过搭配和上下文确定古义、通假及多义 |
| L2 句法 | 识别判断、被动、省略和倒装，厘清施受关系 |
| L3 翻译 | 核对关键词和句式，说明失分位置 |
| L4 篇章 | 概括、人物评价、双材料比较和原文取证 |
| L5 应试 | 按时间完成真题，复核得分与失分原因 |

教师讲义可以放在自己工作区的 `文言文教学/教师备课资料/原始资料/`，请 Skill 建索引。第三方资料随附来源、版本和许可。课堂选段、注释和评分以本课教材与教师要求为准。
