# 文言文备课 Skill

给小学、初中和高中语文教师用的本地备课工具。按篇目和年级查课文、古籍底本与字词书证，设计教学活动、练习及独立的教师答案。附一套《论语》试讲样例。

## 使用

1. 在 GitHub 选择 **Code → Download ZIP**，完整解压。选择同时包含 `.agents` 和 `文言文语料库` 的文件夹作为工作区。
2. 在 Codex 输入 `$wenyan-lesson-prep`。在 DeepSeek Harness 可以尝试输入 `/wenyan-lesson-prep`。本版本已在 Codex 和本地查询工具中验证。
3. 例如输入「备七年级《〈论语〉十二章》的 15 分钟片段课。比较两处『而』，附课堂追问、三道练习和单独的教师答案。」

本地查询使用 Python 3.11 或更新版本。老师可以在自己的工作区创建 `文言文教学/教师备课资料/原始资料`，存放讲义并让 Skill 更新索引。
