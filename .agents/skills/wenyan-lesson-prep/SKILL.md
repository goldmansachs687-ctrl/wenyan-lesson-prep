# 文言文备课

按老师这次要用的材料交付。问一个考点就做对比例句和讲法。要一节课就做可照着上的教案。要印发练习时，学生题与教师答案分别交付。

## 先找老师已有的资料

在有教师资料的项目内，入口是工作区的 `文言文教学/教师备课资料/从这里开始.md`。老师要求查找、归纳或基于自己资料备课时，先用本 Skill 的 `scripts/lookup.py "守株待兔" --teacher --text`，把示例词换成篇目、字词或主题。结果附命中的小节、页码或表号，再按位置核对原稿。无法运行脚本时，直接翻 `索引/原稿目录.md` 与 `篇目笔记/`。

- 只读与本课有关的笔记、原稿段落和表格行。引用列出原稿文件名及小节、表名或 PDF 页码。摘录的行号可以帮助定位，原稿中的颜色标注和排版以 Word、PDF 为准。
- 老师这次指定的原文和采分点优先。不同讲义的选段或译法分别列出，老师的整理稿、古籍底本和新拟题都注明出处。发现可能的笔误时在篇目笔记里标明位置和建议，原稿留存。
- 老师要求将新材料归档时，用同目录的 `资料归档.py import` 原样复制。成套目录用 `--root 路径` 保留层级，单独文件可用 `--folder 分类名` 放进相应学段或专题。运行 `生成原稿索引.py`（新 PDF 用带 pypdf 的 Python）；若项目有统编目录，同步运行 `生成篇目导航.py`。按 `篇目笔记模板.md` 记录重点、来源、页码或小节、练习位置和核对状态。老师确认之后，把确认的讲法和课后观察写回篇目笔记。

## 备课依据

- 从用户给出的年级、篇目、课时和重点开始。缺少可由老师调整的信息时，先写明合理假设再备课。比如已经指定七年级和一整节课，可以按 45 分钟拟稿。
- 老师提供的课文和采分点作为本课依据。古籍、校勘本和题库可用于比较和迁移。发现不同字形、断句或译法时，标明出处与差异。只有篇名时，可以用核实过的节选备课，记清出处和范围。同名篇目先核对学段和选章，例如不同学段的《论语》十二章选章不同。若任务必须对应特定教材且原文尚缺，先做有依据的部分，并指出老师需要补的段落。
- 归纳学生问题时，把老师已确认的错项作为学情证据。只有老师描述和少量样例时标出样本范围。没有学生作答时写「预设易错点」。对含卷面的材料，只带入备课所需的考点、匿名化例句和汇总。看不清的批改或字迹保留待核对。

## 做中考、高考专题复习

读工作区 `文言文语料库/教学参考/复习/中考高考文言文复习.md`。从教师讲义或目标地区、卷型的真题确定范围，按学生要完成的阅读动作组织课内回顾、专项练习和陌生材料复测。每题标明原文依据、可接受答法和采分点。真题和自拟题分别标清，地区、年份、卷型、分值或频率只按有出处的材料填写。没有卷别时可先给通用专题练习。

## 查词和找原句

需要核对课内版本或查生字时，可用同一个 `scripts/lookup.py`。

- `"论语十二章" --course --grade "七年级" --text` 查条目的册次、教材来源和可对照的正文。高中同名篇目用 `--grade "高中"`。返回的「古籍底本参照」「公开课文整理本」是校对材料，课堂选段和采分口径按老师书本。留意仍在用旧版核对的换版册次。
- 明确使用五四学制时加 `--school-system 五四`，例如 `"关尹子教射" --course --school-system 五四 --grade "六年级" --text`。区分已经核对的原册目录、该册已核的选段和跨学制共享底本。背诵、标点及翻译题先核实际教材字形和范围。
- `"顾" --dictionary --limit 4` 查《康熙字典》《说文解字》和有书证或标明书面语的词义。结果里的书证、字形和释义先放回题目句子核对。给学生解释时写明本句为什么取这个义，避免把字书原注或简繁候选直接当教材注释。
- 做易混义项对比时，先列原句和动作对象、指代或句法线索，再列可用义项及出处。需要单查一部时用 `--source kangxi`、`--source shuowen` 或 `--source wiktionary`。附常用义项时将「字书候选」「课堂采用义」分开，并把异体、简繁转换与句中特定的通假现象分别核定。词典未收复合词时，回本句与课内原注或老师讲义核对。

1. 有必要查不同语境时，按本 Skill 的实际路径运行 `python -X utf8 "<Skill 目录>/scripts/lookup.py" "而" --category "虚词" --title "论语" --limit 4`。脚本先查内置课堂知识表，也可以查同工作区的本地词表和古籍语料。查询结果需放回语境。高频词的次数属于江西 2014—2025 年中考样本。
2. 若 Python 不可用，直接读取 [课堂知识表](references/classroom.json)。只读和本次考点有关的条目。有适用原句才引用，保持原字和出处。需要特定教材版本或跨篇迁移材料时，优先核对老师给的材料。引用公开原文时，记录篇名、底本及可核对出处。查不到可靠的外篇例句时，可在本篇换问法，或使用标明「自编」的例句。
3. 出题前逐题核对题干的引文、可接受答法和分点依据。涉及一词多义、古今异义和活用时，说明学生从句中的哪个词或结构可以作判断。

## 给老师的交付

- **查考点或备一段讲解**。给原句、语境义、判断线索和一个能看出学生是否读懂的课堂追问。对比题要把相同字词放在至少两个完整语境里。
- **备一课、设计活动或出卷**。读 [课堂与练习设计](references/lesson-design.md)，按老师要求的课时和任务取用。教案包括可检查的目标、课堂步骤和当堂检查。练习逐题给考点、可接受表述、判分依据，答案放在教师部分。默认可以给三道难度递进的小题，按用户要求的数量和题型优先。
- **交付文件**。老师要求可保存、打印或导出时，把同一篇目和节次的教案、学生练习和教师答案放入教师资料的 `备课产物/`。没有教师资料目录时按工作区约定存放。学生版只放题干和作答要求。无法写文件时，在对话里分开给出可复制的完整文本。
