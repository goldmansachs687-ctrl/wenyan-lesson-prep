# 语料收录说明

这份说明回答三个问题：**包里有哪些语料、为什么不是全部、想要全部怎么拿。**

## 分层原则

老师第一次用这个包，只需要能查课文、查字典、跑通验收、打印分级题。所以默认包只带 Skill 运行与备课真正需要的文件：**下载快、零死链、零许可争议**。

完整的第三方语料（约 135 MB）留在本地开发工作区，需要的人按下文方法自行补齐。这不是资料缺失，是有意分层——把 135 MB 和 20 个指向上游仓库的死链一起塞进 `main.zip`，只会抬高老师的第一道门槛。

## 想拿完整语料

需要联网，约 135 MB。建议在**副本目录**操作，不要覆盖你正在用的包：

```powershell
cd 文言文语料库
Copy-Item 下载清单-完整.json 下载清单.json
python -X utf8 fetch_corpora.py
```

脚本按固定版本下载缺少的文件、检查格式并生成 SHA-256 清单；已有文件只做校验。课堂检索可试 `python -X utf8 查语料.py 守株 --limit 5`。

## 隐私边界

本包**不含**任何老师原稿、备课产物、篇目笔记或索引摘录。这四类目录由 `.gitignore` 排除，打包脚本只创建两个空目录占位，不写入内容。老师的讲义和学生作答请放在各自的工作区，分享卷面前先去掉姓名、学号等可识别信息。
